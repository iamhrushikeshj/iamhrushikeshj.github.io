# Hrushikesh Uday Joshi — Portfolio

Personal portfolio site for a Network Engineer specializing in ISP infrastructure, FTTH, and wireless networks. Built with plain HTML/CSS/JS and hosted on GitHub Pages.

## 🚀 Deploy to GitHub Pages

1. Create a new repository named **`<your-username>.github.io`**
   (e.g. `hrushikeshjoshi.github.io` — replace with your actual GitHub username).
2. Upload `index.html`, `style.css`, and this `README.md`.
3. Go to **Settings → Pages**.
4. Under **Source**, choose **Deploy from a branch** → branch: `main` → folder: `/ (root)`.
5. Click **Save**. Site goes live at `https://<your-username>.github.io` in ~1–2 minutes.

## ✏️ Customize

- **Contact info:** Search `index.html` for `testmail@test.com`, `99999`, and `testlinkedin`.
- **Project links:** Replace the placeholder `https://github.com/` URLs in the Projects section with your real repos.
- **Colors:** Edit the CSS variables at the top of `style.css` (`--accent`, `--bg`, etc.).
